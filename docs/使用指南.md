# 任课教师工作台使用指南

这份指南按第一次建班、日常上课、考试分析和迁移备份的顺序说明。按钮名称以当前软件界面为准。

工作台面向电脑浏览器，适合任课老师管理多个班级的同一学科。下载并解压完整软件包后，用 Chrome 或 Edge 打开 `index.html`，即可使用班级、课表、作业和成绩等功能；这些日常功能无需联网。外部 AI 接口需要网络和相应服务账号。

## 一、第一次打开：先试用，再录入自己的班级

1. 选择老师形象，填写「怎么称呼你」和「任教学科」。
2. 想先熟悉功能，选择「先看看示例数据」；准备直接使用，选择「直接用我的班级」。
3. 直接使用时，在「我教的班级」填写班名，多个班用顿号分隔，再选择「学段」和「课桌」。
4. 点击「开启工作台」。示例模式中的班级和学生都是虚拟数据。
5. 试用结束后，点击左下角「开始录入我的班级」，填写自己的班级等信息，再点「清空并开始」。
6. 到「设置 → 个人信息」核对学科、学段、「开学日期」和「学期结束」。日期会影响教学周、进度推算和日历导出。

日常修改会自动保存到当前浏览器的本地存储。请固定使用同一浏览器、同一用户配置和同一个打开位置，并通过备份文件迁移数据。

## 二、建立班级和座位

1. 在「课堂」顶部点击「+」（新建班级），或进入「设置 → 我教的班级 → 新建班级」。
2. 填写班级名称、教室等信息；班名尽量与现有名单里的写法一致。
3. 选择「每张桌子」的排列方式，例如「单人单列」或「双人同桌」。
4. 「行列」可选「按人数自动排」；需要贴合实际教室时，选「自己设定」调整列数或组数、排数。
5. 「学生坐哪儿」可选「按学号横着排」或「按学号一组一组竖着排」。
6. 初次建班可在「学生名单」直接粘贴姓名，一行一人；也可以留空，点击「创建班级」后批量导入。

以后调整布局，先切换到对应班，再点「班级与桌椅」。进入底部「调座位」后，可以拖动学生，或先点学生再点目标座位；调整错误时点「撤销」。

需要讲台边座位时，使用「讲台两边加座位」，再把学生移过去。「恢复按学号排」会重新安排全班座位，讲台两边会空出来。

## 三、从 Excel 导入学生

1. 打开「学生名单」，选择目标班级，点击「批量导入」。
2. 核对弹窗中的「导入到」。如果表格有「班级」列，且班名匹配现有班级，会按表格分班；无法匹配的行会进入「导入到」指定的班级。
3. 在 Excel 中复制包含表头的整块名单，粘贴到输入框；也可点「选择 CSV 文件」。这里不直接读取 `.xlsx` 文件。
4. 查看识别到的人数和列数，再点「导入」。导入后逐班核对人数、学号和姓名。
5. 单个学生的补录、修改分别使用「添加学生」和名单行上的「编辑」。

只有「姓名」列必需。建议保留学号，跨班导入时同时保留班级列。下面的表头可直接用于整理名单：

```text
学号	姓名	性别	班级	标签	备注
0301	张三	男	初二（3）班	课代表	
0302	李四	女	初二（3）班		
```

也可点击「下载模板」获取 CSV 模板。CSV 请保存为 UTF-8，学号有前导零时先在 Excel 中设置为文本。

重复导入不是批量更新：同班同名且学号相同的记录会跳过；未提供学号时，同班同名也会跳过。修改已有学生资料，请使用「编辑」，避免改动学号后再次导入造成重复。未填写性别的记录默认按男生处理，导入后请核对。

## 四、排课表、调课和导出日历

先到「设置 → 作息时间」核对每天的节次及开始、结束时间，再排课。修改作息模板或删除节次可能移除对应安排，已有课表时先备份。

### 固定课表

1. 打开「课表」，点击要安排的星期与节次交叉格。
2. 在「安排」中选择班级，核对「类型」，按需填写「教室 / 地点」和「备注」。
3. 在「适用范围」选择「每周都这样（固定课表）」，点击「保存」。
4. 教研、值班等选择「教研 / 值班等事务」；删除固定安排时选择「空」，仍用固定课表范围保存。
5. 查看右侧「课时统计」，核对各班每周正课数。

### 临时调整

- 只改某一天：先切换到正确周，点对应格子，选择「只改 ×月×日 这一次」后保存。按钮中的日期会随格子变化。
- 挪到另一节：打开原课程，点「把这节课调到别的时间…」，选择「调到哪天」和「第几节」。目标已有课程时，可选择「两节课对调」。
- 单节停课：选择「空」，适用范围选当天这一次。
- 全天停课：点课表顶部的日期，填写「原因」，点击「设为停课」；再次点该日期可「恢复上课」。
- 撤销临时调整：在右侧「调课与停课记录」找到记录，点击其撤销按钮。

排好后可「打印课表」，或点击「导出到手机日历」下载 `.ics`。导出的日程包含课前 10 分钟提醒及已有调课、停课安排；用支持 `.ics` 的日历应用导入，并核对时间。

导出文件不会随工作台自动更新。课表改变后重新导入前，先清理旧课程，避免重复提醒；可将教学课表导入单独的日历，方便替换。

## 五、登记教学进度

1. 打开「教学进度 → 编辑课题」。
2. 每行填写一个课题，后面用空格或 Tab 分隔计划课时；也可从教学计划复制两列。未填课时按 1 节计算。
3. 点击「保存」，核对课题数和总课时。例如：

```text
11.1 与三角形有关的线段	3
11.2 与三角形有关的角	2
第十一章复习	1
```

4. 某个班讲完一个课题后，点「课题清单」中该课题与该班的交叉格，默认记录今天完成。
5. 再点已完成格，可修改「完成日期」，或点「标记为未完成」。在「课堂」的「上课」模式也能点「这个课题讲完了」。

各班共用一份课题清单，分别记录完成日期。「快 / 慢几个课题」按开学日期、课表中的已过正课和计划课时推算，仅作参考。课表或停课记录不准确，推算也会偏差。

课题改名或删除会使原有对应完成记录被移除。开始登记后尽量保留课题名称；需要整理清单，先「导出」进度表并保存完整备份。

## 六、布置作业与检查上交情况

1. 打开「作业 → 布置作业」，填写「作业内容」，选择一个或多个班级。
2. 选择「类型」，核对「布置日期」「上交日期」，按需填写「要求 / 备注」，点击「布置」。
3. 多班布置会为每个班建立独立记录。上交日期会参考各班下一次上课，请布置后逐班核对；需要统一日期时，分别点击「编辑」调整。
4. 选中要检查的作业，点学生卡片切换状态：未登记 → 已交 → 优秀 → 需订正 → 未交。
5. 可以先把少数未交、优秀或需订正的同学标出来，再点「其余都已交」，补齐未登记人员。
6. 点「复制未交名单」获取文字，核对班级和作业名称后再分享；点「导出记录」可下载 CSV。

课堂中也可切到「作业检查」，先选对作业，再逐个登记。不要把「未登记」当成「未交」：上交率按“已交（含优秀、需订正）÷ 已登记人数”计算，检查未完成时会高估全班的实际完成情况。

## 七、考试录入：先定义试卷，再填分数

### 新建考试

1. 打开「成绩录入 → 新建考试」。
2. 填写「考试名称」「考试日期」，选择「类型」和所有「参考班级」。平行班要放在同一场考试中，才能直接横向对比。
3. 选择「只录总分」，填写满分；或选择「按大题 / 题型录入」，设置每项名称和满分，总满分由各项相加。
4. 点击「创建并录入」，在班级标签间切换录分。

分项名称需在录分前确定。已有成绩时改名会让该项分数无法对应；更改录入方式、删项或改参考班级前，先备份。

### 三种录入方式

| 方式 | 操作 | 适合情况 |
|---|---|---|
| 逐格填写 | 点击成绩格输入，回车到下一位学生 | 少量补录或更正 |
| 整块粘贴 | 在 Excel 按工作台学生顺序复制纯分数区域，再点工作台起始成绩格粘贴 | 名单与列顺序完全一致 |
| 按表头导入 | 点击「按表头导入」，粘贴包含表头的成绩表，核对匹配人数和识别列后点「导入」 | Excel 排序不同，或多个班混在一张表 |

整块粘贴按位置填入，不按姓名匹配。复制时不要带表头、姓名和学号。使用「按表头导入」时，至少有「姓名」或「学号」列；多班学号可能重复，建议同时带上「班级」「学号」「姓名」。

总分列可叫「成绩」「分数」「总分」等；分项列名须与考试设置一致，例如「选择题」「填空题」「解答题」。导入会写入匹配学生的已识别分数列，可覆盖原分数；空白单元格不会清除原分数。

- 缺考填「缺」，不能用 0 代替；分项模式下，整场缺考应在所有分项填「缺」。
- 真正得 0 分应输入 `0`；空白表示未录入。
- 负分或超过满分的输入会标红，应更正后再分析。
- 分项只录了一部分时，已有数值仍会相加并进入统计。先核对「已录」人数，补齐分项和缺考记录，再使用分析结果。
- 录入完成后点「导出」保存 CSV，或点「看分析」查看结果。

## 八、读懂成绩分析

1. 打开「成绩分析」，在顶部选择本次考试和「对比」考试；不需要历史比较时选择「不对比」。
2. 多班考试可看「全部 × 个班」，或点击某个班名看班内情况。
3. 先核对参考人数和满分，再看平均分、及格率、优秀率、低分率及「本次要点」。
4. 按大题录入的考试可查看各项得分率，把得分率较低的题型作为讲评和练习的依据。
5. 查看临界生及进退情况，点击学生姓名打开详情，结合历次成绩、作业和课堂表现判断。

「平行班名次」只涵盖这场考试选中的班级；只有录入所有相关班级时，才可将它当作更大范围的排名。不同满分的考试比较时关注得分率，也要结合试卷难度、参考范围和数据完整性。

及格线、优秀线、低分线在「设置 → 成绩线与点评」中按满分百分比设置。临界生范围为距离相应分数线向下 5% 满分以内。整场缺考不计入分数统计。

投屏前先检查页面内容。「成绩」模式、成绩分析及学生详情可能展示个人分数、名次和备注，不宜在不适合公开的场合展示。

## 九、保存备份、换电脑和更新文件

1. 在「设置 → 数据与备份」查看「存储状态」和「上次备份」。
2. 点击「导出备份」，保存下载的 `.json` 文件。建议在批量录分后、每周结束及重要删除前各留一份，并保留多个日期版本。
3. 换电脑、换浏览器、改用在线地址或更新软件前，先在原位置导出备份。
4. 在新位置打开工作台，进入「设置 → 数据与备份 → 从备份恢复」，选择 JSON，核对弹窗中的班级、学生和考试数量，再点击「恢复」。
5. 恢复后抽查名单、课表及最近成绩，再继续使用。

恢复会覆盖当前全部数据，不会与当前班级合并。先备份目标位置已有数据，再执行恢复。CSV 导出适合查看或交接表格，不能替代完整 JSON 备份。

备份包含学生资料、成绩、作业、AI 对话和 AI 设置；已填写的 API Key 也在其中，文件没有另行加密。请存放在受控位置，不要把真实备份上传到公开仓库或随软件包分发。

仅复制 `index.html` 不会带走已录入的数据。清理浏览器数据、使用隐私窗口、删除浏览器用户配置，都可能造成数据丢失；浏览器禁止本地存储时，页面关闭后数据可能无法保留。出现存储异常提示，请立即导出备份。

## 十、可选的 AI 教学助理

### 不配置接口：复制提示词

进入「AI 助手」选择任务模板，填写课题、班级或考试等选项，使用「复制提示词」。检查文本中的学生资料后，可自行粘贴到所用 AI 服务。复制本身不会调用外部 AI；提交到其他服务后，资料由该服务处理。

### 在工作台中直接生成

1. 到所选服务商获取接口权限和 API Key，再打开「设置 → AI 接口」。
2. 选择「服务商」，填写「API Key」「接口地址（Base URL）」和「模型名称」。模型名称及权限以自己的服务商控制台为准。
3. 保持「发送前隐去学生姓名」勾选，点击「测试连接」。测试会向配置的接口发送简短测试消息及鉴权信息。
4. 连接成功后，回到「AI 助手」选择模板，核对要附带的班级、学生、考试或学情，填写要求后生成。
5. 阅读并核对生成结果，可「复制」或「导出 Word」。用于出题、评语和家长沟通前，仍需老师审核内容。

日常数据及 Key 的保存位置是本地浏览器；调用 AI 时，选中的资料、提示词、相关对话及 Key 鉴权信息会发送到配置的接口。若接口是中转服务，资料也会经过该中转。费用、留存和使用规则由实际服务商决定。

姓名替换为编号只是一项辅助保护，不等于完整匿名化；班级、备注和自由输入文字仍可能识别学生。请仅发送教学任务所需资料，并按学校对学生信息的要求使用。只有配置为实际运行在本机的模型服务时，请求才可能在本机完成；外部 AI 不能视作离线功能。

### 接口正确但网页连不上

部分接口限制浏览器跨域调用，可选用软件包中的本地转发工具。电脑需要 Node.js 18 或更新版本，在软件包目录打开终端运行：

```bash
node ai-proxy.js
```

保持终端窗口开启，在「接口地址（Base URL）」前加 `http://127.0.0.1:8787/`。例如原地址 `https://api.deepseek.com` 改为 `http://127.0.0.1:8787/https://api.deepseek.com`，再「测试连接」。用完按 `Ctrl+C` 停止。

该工具在本机转发请求，并继续向原服务商发送资料和鉴权，不会把外部服务变成本地模型。它不代替有效 Key、模型权限或可用网络。

## 十一、常见问题排查

| 现象 | 先检查什么 |
|---|---|
| 再打开后看不到原数据 | 是否换了浏览器、用户配置、文件位置或在线地址；回原位置查看，或从 JSON 备份恢复 |
| 名单提示没有「姓名」列 | 第一行是否为表头；不要把标题、空行或说明文字一起复制；可下载模板 |
| 名单进错班级 | 表中班名是否与现有班名匹配，以及导入弹窗的「导入到」是否正确 |
| 成绩错行或少人 | 整块粘贴是否按相同学号顺序；跨班同学号请用包含班级的表头导入，并核对匹配人数 |
| 没有平行班或分项分析 | 是否在同一场考试选择了多个参考班级，是否使用分项录入并填齐分数 |
| 教学进度快慢不合理 | 开学日期、固定课表、课的类型、临时停课、计划课时和完成日期是否准确 |
| AI 提示鉴权、模型或额度错误 | Key、接口地址、模型名称、账号权限和可用额度；不能只靠本地转发解决 |
| AI 转发提示端口被占用 | 是否已经开过一个转发窗口；避免重复启动，先检查已有窗口 |
| 想重新看示例 | 「设置 → 数据与备份 → 载入示例数据」会覆盖当前数据，务必先导出备份 |
